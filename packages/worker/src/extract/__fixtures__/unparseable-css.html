Nested CSS Trips jsdom's Parser

This is a normal, readable article body. It exists only to give Readability enough prose to extract text from, so the test can prove that a stylesheet jsdom cannot parse does not prevent DOM construction or readable-text extraction — only the noisy log line is suppressed, nothing about parsing behavior changes.

The stylesheet above is never applied to this text in any way that matters here: jsdom does not run layout or apply CSS when Readability reads the DOM, so an unparseable stylesheet has zero effect on the extracted content itself, only on what gets logged while jsdom builds the document.
