# silo

An agent-native personal link store — feed in web material (links, Twitter/X, HN, videos) captured with rich metadata + full text, organized by tags + notes, searchable, and served over MCP so an external agent does the intelligence. No AI inside silo itself.

Planning and design are complete; the stack is deliberately undecided. Start with **[`docs/`](docs/README.md)** — scope, foundation checklist, design system, and the captured UI prototype.
